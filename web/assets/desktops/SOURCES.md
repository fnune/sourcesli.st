# Desktop screenshot sources

Cropped to 16:9 and downscaled from Wikimedia Commons on 2026-08-07. Every file is one frame of Debian 13.0.0 booted from its own live image, so a tile shows the desktop this site hands the reader rather than the same desktop as some other distribution ships it. All are by The Debian Project under the GPL; each file page carries the licence.

- `gnome.webp`: <https://commons.wikimedia.org/wiki/File:Debian_13.0.0_GNOME_Files_48.3_default_-_English.png>
- `kde.webp`: <https://commons.wikimedia.org/wiki/File:Debian_13.0.0_KDE_menu_-_English.png>
- `xfce.webp`: <https://commons.wikimedia.org/wiki/File:Debian_13.0.0_Xfce_menu_-_English.png>
- `cinnamon.webp`: <https://commons.wikimedia.org/wiki/File:Debian_13.0.0_Cinnamon_menu_-_English.png>
- `mate.webp`: <https://commons.wikimedia.org/wiki/File:Debian_13.0.0_MATE_Applications_menu_-_English.png>

Four of the five are the applications menu open over an otherwise untouched desktop. GNOME has no such menu and its bare desktop is only a wallpaper, so it gets its file manager instead, which is where its shell and window style show. The originals are 3:2, so the crop drops the sixth of the screen furthest from the subject: the desktop's own panels survive, which is what a reader at tile size is comparing.
